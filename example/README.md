# Example application

No application exists in this directory.
Create the Expo example application during the sampling spike. Use the then-current Expo and React Native versions.

## Spike fixture (delivery step 1)

The application must contain one fixture with these parts:

- An image as the background.
- A transparent or translucent overlay above the image.
- A movable foreground above the overlay.
- A display of the sampled RGBA, the resolved RGBA, the selected foreground, and the contrast ratio.

## Demonstration (delivery step 4)

The application must demonstrate these cases:

- Solid colors.
- Images.
- Transparency.
- Gradients.
- Samples that move.
- Recomputation after a background change.
- Visible errors.

Add real platform screenshots from this application to the root README in step 4.
